# Proyecto: Hábitos Saludables

Este repositorio contiene la documentación de hábitos saludables en archivos de texto, gestionada mediante control de versiones con Git y GitHub.

## Proceso Realizado
1. **Configuración inicial**: Configuración de credenciales de Git (user.name y user.email).
2. **Creación de documentos**:
   - `alimentacion.txt`: Información sobre nutrición y reducción de azúcares.
   - `ejercicio.txt`: Recomendaciones de actividad física para la salud cardiovascular.
3. **Control de versiones**: Uso de comandos `git add`, `git commit` y `git push` para registrar y sincronizar los cambios con GitHub.
# Proyecto: Hábitos Saludables

Este repositorio contiene la documentación de hábitos saludables y la gestión del control de versiones mediante Git y GitHub.

## Estructura del Repositorio y Proceso Realizado
1. **Configuración inicial**: Configuración de credenciales de Git (`user.name` y `user.email`).
2. **Archivos de texto principales**:
   - `alimentacion.txt`: Información sobre nutrición y reducción de azúcares.
   - `ejercicio.txt`: Recomendaciones de actividad física para la salud cardiovascular.
3. **Tutoriales en PDF (Basados en Pro Git)**:
   - `Tutorial de Git - Capitulo 1.pdf`: Documentación y resumen del primer capítulo sobre control de versiones y fundamentos iniciales.
   - `Tutorial de Git - Capitulo 2.pdf`: Documentación y resumen del segundo capítulo sobre los comandos básicos de Git (`add`, `commit`, `push`).
4. **Control de versiones**: Uso de comandos en Git Bash para registrar y sincronizar los cambios con GitHub de forma estructurada.
